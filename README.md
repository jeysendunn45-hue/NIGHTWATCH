# NIGHTWATCH

**A small, original browser survival-horror game.** Find three backup fuses, restore the south gate, and escape the thing stalking the grounds.

## Play

Open [index.html](./index.html) in a modern browser, or enable GitHub Pages in **Settings → Pages** and deploy from the `main` branch / root folder.

## Controls

- **WASD / Arrow keys:** Move
- **Mouse:** Aim the flashlight
- **F:** Toggle flashlight
- **Space:** Throw a noise lure (two per shift)
- **C:** Toggle the experimental motion trace
- **Esc:** Pause
- **E:** Interact with the gate when nearby and all fuses are collected

Touch movement controls are included for smaller screens.

## The rules

- The Watcher follows your last known position and hunts when you're nearby.
- Shine the flashlight directly at it to slow it down, but the light drains your power cell.
- Noise lures pull it away for a short time.
- Collect all three glowing fuses, then reach the south gate.

## Project

- No frameworks, build step, or external assets required.
- Built with HTML, CSS, Canvas 2D, and vanilla JavaScript.
- Original placeholder art is drawn in code.
